Funky Monkeys Uploader

Funky Monkeys Uploader is a private tool used only by the owner of the Funky Monkeys Toons YouTube channel to upload and schedule the channel's own original animated Shorts.

It uses the YouTube API Services to upload videos, set their titles, descriptions, tags and publishing schedule, and list the channel's videos. It is not offered to the public and does not access any other user's account.
